# Lee 信息首页 V2

打开 `Lee_信息首页.html` 可直接使用中文离线快照。点击原文后，可用 Safari 翻译网页；影视必须另有经过核验的中文音轨或字幕，网页翻译不能代替字幕翻译。

先筛来源，再按具体内容的兴趣关联、相邻探索、信息密度、阅读体验、可继续性评分。低于 6 分、不具备具体内容依据或无可靠中文观看方式的影视不进入主推荐。每天首次展示 8 条，最多接触 12 条；后台更新扩充候选池，不替换当天未处理的内容。

支持兴趣反馈、访问失败暂停、收藏备注、摘录、内容线索、复制给 Chat、个人笔记和本地备份。私人数据不上传 GitHub。

项目内含 GitHub Pages + Actions 配置，每天北京时间约 08:17、17:17 运行。实际部署状态见仓库 Actions。实现与测试说明见《实测问题修复说明》。
